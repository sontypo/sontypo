# How to install this GitHub Profile README

GitHub username:

```text
sontypo
```

Create a **public** repository named exactly:

```text
sontypo
```

The resulting repository will be:

```text
https://github.com/sontypo/sontypo
```

Put the included `README.md` in the root of that repository.

GitHub will then show it at the top of:

```text
https://github.com/sontypo
```

## Before publishing

Search `README.md` for:

```text
PLACEHOLDER
ADD_EMAIL
ADD_LINK
](#)
```

Replace those with your real:

- Google Scholar link
- LinkedIn link
- email
- research/project links

Your interactive portfolio is currently linked as:

```text
https://sontypo.github.io
```

Deploy the portfolio repository as:

```text
sontypo.github.io
```

to make that link work.
